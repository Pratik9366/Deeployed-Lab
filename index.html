Curriculum

12-Week Learning Path

A carefully structured curriculum that takes you from zero to Python-proficient, ready for AI & Data Science.

1-2

Python Basics & Setup

Weeks 1–2
  • Installing Python & IDE setup
  • Variables, data types & operators
  • Input/output & string formatting
  • Writing your first programs
3-4

Control Flow & Logic

Weeks 3–4
  • Conditional statements (if/elif/else)
  • Loops — for & while
  • Nested loops & pattern programs
  • Logical operators & boolean logic
5-6

Data Structures

Weeks 5–6
  • Lists, tuples, sets & dictionaries
  • List comprehensions
  • String manipulation deep dive
  • Practice problems & mini projects
7-8

Functions & Modules

Weeks 7–8
  • Defining & calling functions
  • Parameters, return values & scope
  • Lambda functions & built-in functions
  • Importing & creating modules
9-10

OOP & File Handling

Weeks 9–10
  • Classes, objects & constructors
  • Inheritance & polymorphism
  • File I/O — reading & writing files
  • Exception handling (try/except)
11-12

AI/DS Pre-requisites & Capstone

Weeks 11–12
  • Intro to NumPy & Pandas
  • Basic data visualization with Matplotlib
  • Capstone mini project
  • Next steps — AI & ML Fundamentals preview
